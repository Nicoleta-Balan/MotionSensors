This project demonstrates the implementation of device motion sensors in Android. 
It was developed as an educational project for a tutorial paper in the Mobile Applications course (SDBIS Master's program, FEAA Iași, 2026)

Motion sensors used: Gyroscope + Accelerometer
Real-time Axis Tracking: Implements sensor event listeners to capture and process movement data across the X, Y, and Z axes.
The background color of the MainActivity changes instantly based on the data received from both sensors
Battery Optimized: Configured to run on the `SENSOR_DELAY_NORMAL` sampling rate, ensuring efficient battery consumption during operation.
